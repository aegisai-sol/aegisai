How rewards work

  • 10B max · 85% mining · 10% team · 5% ecosystem.
  • Wallet-first: no Phantom connect → no Start, no Claim. Rewards mint to that wallet.
  • Power × graded work: Phone ×1 · Laptop ×2.5 · Server ×6 (claim caps tier share at ×2). Server grades PoV-R answers (≥90%).
  • Difficulty stays 1.00 until 100 wallets claim today, then FREE/active so more miners share the same emission.
  • Halving every ~2 years · Bigger RWA = more AGIS.
unit   ≈ 0.006738 AGIS × min(tier,2) / 2^era × (D_bps/10000)
D_bps  = 10000 while activeWallets ≤ 100; else 10000×100/active
rwa    = 2 × unit × size × duration × compute
size     = 1 + log2(1 + bytes/256KB)
duration = 1 + min(4, pages/10)
compute  = doc 1 · image 1.5 · deed 2 · finance 2.5
caps: 25 AGIS/job · 100 AGIS/wallet/day · 100k AGIS/network/day

On-page numbers are estimates from the same rules as the claim server; a paid claim shows live difficulty and active wallets.

Open this page → Share → Add to Home Screen. Open icon → Connect → Start. (iOS pauses when locked.)

Chrome/Edge → install icon in address bar. Keeps mining in a background window.
