Seal vs Verify — in plain English
Where things live: the fingerprint is made free on your phone and stays on this device only until you tap Put on Solana. Then a Solana Memo (Seal ID + fingerprint + time — not the file) is a permanent public proof anyone can check, even if our site goes away. Your original file never leaves your phone.
Seal = create a stamp: pick a file, tap Seal, save your Seal ID. About 20 s later it shows verified.
Verify = check a stamp: paste the Seal ID, open the proof link, or upload the same file again.
Nobody sees your file — only the stamp status, expiry and Solana receipt.
Quick rule: “Stamp this file now” → Seal · “Is this stamp still good?” → Verify. Full simple guide
Tamper-proof: change even 1 pixel and Verify shows no match. No human or AI reads your file. Why originality holds

Timestamped integrity seal on Solana (photo, PDF, CSV…). Proves unchanged bytes at seal time — not a government notary (eIDAS).

Invoice, receipt, deed scan, PDF, photo, video, Excel. We make a fingerprint (SHA-256) in your browser, network miners check it is intact, and Solana stores a receipt (fingerprint + result + time). The file itself never goes to the chain in plain form.

🔒 We cannot see your document — only you, with your key.
Help — why seal, and where things live

Real-life uses: prove an invoice, photo, contract or report existed in this exact form at a given time — for disputes, insurance, deliveries, IP or audits. A seal proves this file existed unchanged at time T. It does not prove who wrote or issued it.

Where each piece lives

  • Original file — only with you. We never store it.
  • Fingerprint on this device — free; lost if the device or browser data is wiped before a Solana stamp. Durability: low.
  • Encrypted backup ⚠ — Aegis servers, encrypted, no key with us. Not blockchain. Durability: medium, best effort.
  • Solana stamp — public Memo (Seal ID + fingerprint + time). Durability: highest; checkable by anyone via Solana RPC.
  • L4 (in prep) — encrypted full file package you can pin to IPFS/Arweave; blob hash designed for Solana. Auto-pin not live yet.
  • Extra lock (optional) — a passphrase wraps the seal key on this device so an unlocked stolen phone is not enough. Skip anytime; Seal stays fast.

Keep your original file and your Seal ID. With the file + a Solana stamp, you can prove it any time — no key needed.
