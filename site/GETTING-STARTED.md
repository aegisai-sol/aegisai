# AegisAI — Getting Started

**Token (AGIS, Solana SPL):** `GhSiU95vtKwn7FBAW1u5krxYP2PnpFPotb1LJFZkbzhW` — verify on [Solana Explorer](https://explorer.solana.com/address/GhSiU95vtKwn7FBAW1u5krxYP2PnpFPotb1LJFZkbzhW). Beware of fake CAs.

1. **Wallet** — install Phantom, Solflare, Trust Wallet or MetaMask (Solana). Add custom token with the CA above.
2. **Connect** — open the [Miner](https://aegisai-sol.github.io/aegisai/miner.html) → *Connect Wallet*.
3. **Mine** — press *Start*. Rewards = device power × time; bigger/longer RWA jobs earn more; difficulty rises with network size.
4. **Background** — install as app (iOS Safari: Share → Add to Home Screen; Android/Chrome/Edge: Install app). Desktop: download `downloads/aegis-miner.zip`. Note: iOS/Android pause web apps in background; desktop miner runs continuously.
5. **Claim** — when your balance shows mined AGIS, press *Claim* and sign (free message signature). AGIS is sent to the connected wallet.
6. **RWA** — upload documents on the [RWA page](https://aegisai-sol.github.io/aegisai/rwa.html) (encrypted, queued as verification jobs).

**Status (honest):** token is real on mainnet; miner/PWA is live; on-chain payout on Claim is in beta (claim server not yet public — claims are recorded and paid out as the server goes live). **Audit: not yet — planned.** Not financial advice.
