AegisAI — PoV-R

Proof-of-Verification on Solana · Encode Solana Hackathon 2026 mid-checkpoint

1. Problem

  • AI output is everywhere; fake citations and wrong numbers are common.
  • No cheap way to *prove* an AI answer was checked. Centralized checking is costly and opaque.

    • 2. PoV-R

  • Split AI text → micro-claims → small verification tasks for any low-power device.
  • Verdict per claim: TRUE / FALSE / UNSURE + receipt ID.
  • Correct votes earn non-transferable Proof Credits; canaries catch cheaters.
  • Reservoir: credits → AGIS only against real fees paid.

    • 3. Proof-of-Source

  • One method inside PoV: fetch the cited URL, fingerprint the page, check the quote exists.
  • Dead / invalid source → FALSE. Quote found → TRUE. Not reachable/ambiguous → UNSURE.
  • Plus arithmetic/rule checks and calibration canaries.

    • 4. Demo

  • https://bold-thistle-3z5f.here.now/verify.html
  • 3 buttons: Fake citation · Wrong math · Real quote → per-claim verdicts + receipt + credits.

    • 5. Architecture

    Browser / client ──► verify.html (in-browser engine)
        │
        └─► Miner/coordinator  POST /v1/verify
              ├─ claim splitter
              ├─ methods: arithmetic · Proof-of-Source fetch · canaries
              ├─ Proof Credits ledger (off-chain now)
              └─ solana_submit (memo receipts, devnet — next)

    6. Token — Option A

  • AGIS: 1B hard cap, 40% Reservoir, mint authority revoked after genesis.
  • Convert caps: ≤70% of epoch fees, ≤0.5% of Reservoir per epoch.
  • No mint now — tech and product first; token after audited program + liquidity.
