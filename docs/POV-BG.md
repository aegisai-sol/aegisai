# Proof-of-Verification — кратко (BG)

**Проблем:** AI „халюцинира“, а проверката е скъпа. Милиарди телефони и стари компютри стоят без работа.

**Решение:** AegisAI разбива AI отговорите на малки твърдения (micro-claims). Произволно избрани слаби нодове (телефон, PC, сървър) ги проверяват с правила и малък модел (<1 GB). Гласуват с commit–reveal, консенсусът е претеглен по stake × репутация, а резултатът се записва в Solana като проверима разписка.

**Защо е ново:** не е PoW (безполезни хешове), не е само PoS (награда за капитал), не е централизиран fact-check, не е federated learning. Комбинацията „микро-инференс на слаби устройства + консенсус + on-chain атестация + награда за полезна работа“ е новата категория.

**Защити:** уникални задачи, commit–reveal, скрити тестови задачи с известен отговор, минимален stake, репутация, (по-късно) slashing.

**Фази:** mock (сега) → Devnet → малки ONNX модели → mainnet награди → платен Verification API за фирми → децентрализиране.

**Токен:** 1B AGIS, mint/freeze отнети, **15% за разработчика с vesting** (3 м. cliff + 12 м.), 85% публично (награди, ликвидност, екосистема).

**Честно:** MVP-то още симулира проверките. Не е финансов съвет.
