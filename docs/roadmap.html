Roadmap

What works, what we are building, and what comes later. We update this page as things ship.

Now — works today

  • Seal + Solana Memo · live
    Fingerprint a file; you (the sealer) pay the tiny SOL fee and sign the receipt.
  • Mine rewards · live
    Run the miner, earn AGIS for verified work.
  • Network attestation signature · live
    AGIS signs each proof card (Ed25519); check it in the browser on the proof page. Not eIDAS or a notary.
  • Burn AGIS · live
    Real SPL burn from your wallet on Burn/Stake. Supply goes down on-chain.
  • Stake AGIS (vault v1) · live
    Transfer + Memo to a published vault; ledger read from Solana. Custodial in v1.
  • Unstake request · live
    Your unstake request is written on-chain. Returns after the 7-day lock are processed by an hourly network job.

Next — coming days and weeks

  • Fund the stake vault with SOL · next days
    The vault needs a small SOL balance for return fees. Until funded, returns queue and are not sent.
  • Verified automatic unstake return · next days
    First real 7-day return sent and checked on Solscan.
  • Move the return job to a server cron · next weeks
    Hourly job runs today from our ops machine; moving it to a hosted cron for uptime.
  • Supply endpoint fix · next days
    The public supply API is being repaired; on-chain supply is always visible on Solscan.
  • Polish and mobile wallet testing · next weeks
    Copy, error messages, Phantom mobile flows.

Later — after the pool

  • LP on Raydium · later
    First AGIS/SOL pool. No pool exists today.
  • Jupiter / DexScreener · later
    Routing and charts after the pool exists.
  • Pay in AGIS → swap → burn for anchors · later
    Part swapped to SOL for the fee, the rest burned.
  • Stake program — no firm custody · later
    Solana program with a time lock; you unstake yourself, AegisAI holds no keys. Replaces vault v1.
  • Invoice pilot with 1 real firm · later
    Seal invoices inside a real business workflow.
  • Mobile apps · later
  • L3 / L4 durable index · later
    Long-term proof storage beyond our servers.
  • QTSP / notary partner · later
    Qualified signatures only through a licensed partner — we will not imitate them.
