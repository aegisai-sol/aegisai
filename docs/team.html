7 · API surface · base https://agis-claim.onrender.com
GET/api/healthClaim server health, mint, job count
POST/api/claimSigned wallet claim of mined AGIS (≤~100/day)
GET/api/rwa/healthRWA queue health (jobs, open)
GET/api/rwa/jobs?status=open|allList seals (public fields, no ciphertext)
POST/api/rwa/jobsCreate seal: {fingerprint, meta, ciphertextB64?} — key fields rejected
GET/api/rwa/jobs/:id[?full=1]Seal detail; full=1 adds ciphertext for miners/owner
POST/api/rwa/jobs/:id/voteMiner vote, Phantom-signed AEGIS/rwa-vote/v1 message
POST/api/rwa/jobs/:id/keywrapAttach wallet-wrapped key blob (write-once, attach-signed)
GET/api/rwa/by-fingerprint/:sha256Recovery/public proof by file hash (no key)
JSwindow.agisRwaBrowser SDK: health, byFingerprint, createJob, listJobs, getJob, integrityCheck, vote, wrapKey, unwrapKey

CORS open, JSON. Never send keys; server rejects key-like fields. Example: curl https://agis-claim.onrender.com/api/rwa/by-fingerprint/$(sha256sum file.pdf|cut -c1-64)
