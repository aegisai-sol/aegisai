Seal a file · Запечатай файл

Invoice, receipt, deed scan, PDF, photo, video, Excel. We make a fingerprint (SHA-256) in your browser, network miners check it is intact, and Solana stores a receipt (fingerprint + result + time). The file itself never goes to the chain in plain form.

BG: Файлът остава при теб. В блокчейна влиза само разписка (отпечатък + резултат + час). Ако някой промени дори 1 байт — отпечатъкът е различен.

Fingerprint (SHA-256):

Private mode: AES-256-GCM in your browser; save the key — we never see it. Encrypted copy limit for the network in v1: ~2.9 MB (bigger files → public anchor).

Re-select the original file (or paste its fingerprint). We recompute the hash and look for a seal.
